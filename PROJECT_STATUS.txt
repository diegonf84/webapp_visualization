1. PROJECT OVERVIEW
================================================================================

MAIN IDEA:
A web dashboard to visualize and analyze the Argentine insurance market data
from the Superintendencia de Seguros de la Nacion (SSN). The dashboard allows
users to explore market trends, compare companies, and analyze individual
company performance.

TARGET USERS:
- Insurance industry analysts
- Company executives
- Regulatory researchers
- Financial analysts

DATA SOURCES:
- subramos_historico.csv: Premium, claims, expenses by company/ramo/subramo
- otros_conceptos_historico.csv: Investments, patrimony, balance sheet items
- Data is quarterly (Argentine fiscal calendar: Q1=Mar, Q2=Jun, Q3=Sep, Q4=Dec)

3. API ENDPOINTS
================================================================================

FILTERS:
  GET /api/filters                  → years, quarters, ramos, companies

MARKET DATA:
  GET /api/data/kpis                → Market-wide KPIs with filters
  GET /api/data/companies/ranking   → Top N companies by primas
  GET /api/data/distribution/ramos  → Distribution by ramo
  GET /api/data/distribution/subramos → Distribution by subramo

COMPANY DATA:
  GET /api/data/companies/list      → List all companies (for selection page)
  GET /api/data/companies/{cod_cia} → Single company profile with:
      - Accumulated metrics (primas, siniestros, gastos)
      - Current quarter metrics (*_current fields)
      - Results from otros_conceptos (resultado_tecnico, resultado_financiero)
      - Ranking position (by primas emitidas)
      - YoY variations for key metrics
      - ALL ramos breakdown with full metrics (not just top 5):
        * primas_emitidas, primas_devengadas
        * siniestros_devengados, gastos_devengados
        * siniestralidad, gastos_percent, combined_ratio
      - Market averages for same tipo_cia:
        * market_siniestralidad, market_gastos_percent, market_combined_ratio
        * market_companies_count

  GET /api/data/companies/{cod_cia}/operations → Time series for Operations tab:
      - Query param: ramo (optional, filters by ramo)
      - For each period (all available quarters):
        * Accumulated values: primas, siniestros, gastos, resultado_tecnico
        * Current quarter values (*_current): for charts and rolling 12
        * Ratios: ratio_combinado, ratio_siniestralidad, ratio_gastos
        * Market ratio_combinado (same tipo_cia, same ramo if filtered)
      - Available ramos list for dropdown selector

6. DESIGN DECISIONS & PATTERNS
================================================================================

UI PATTERNS:
  - Sidebar: Icons only (w-16), expands on hover (w-56)
  - KPI Cards: Color-coded left borders (blue, emerald, amber, rose, purple)
  - Badges: CVA variants (success=green, warning=amber, destructive=red)
  - Charts: Nivo with consistent color palettes (CHART_COLORS in constants.ts)
  - Responsive: Mobile-first, grid breakpoints (sm, md, lg, xl)

DATA PATTERNS:
  - React Query for all API calls (automatic caching, loading states)
  - View modes: "Acumulado" vs "Trimestral" (quarterly data)
  - Top N filtering for bar charts
  - Dynamic switching between ramos/subramos based on filter selection
  - Fixed colors for RC and Cascos subramos (consistent across ramos)

RATIO THRESHOLDS (for color indicators):
  - Siniestralidad: good < 65%, warning < 80%, bad >= 80%
  - Gastos %: good < 25%, warning < 35%, bad >= 35%
  - Combined Ratio: good < 95%, warning < 105%, bad >= 105%

YOY CALCULATION LOGIC:
  - Compares same quarter previous year (e.g., 202503 vs 202403)
  - Returns null (shows "N/A") if:
    - Previous value is 0 (zero division)
    - No previous year data (new company)
    - Variation exceeds ±1000% (anomaly)
  - Green arrow up for positive, red arrow down for negative

10. KNOWN ISSUES & NOTES
================================================================================

- Mobile responsiveness: Bar chart switches to horizontal on mobile
- The sidebar hover behavior may need refinement (CSS transitions)
- Some companies may have missing data for certain periods
- The "current" columns assume quarterly data (divide by 3 for monthly)
- YoY shows "N/A" for new companies or when previous year data is missing

DATA HANDLING NOTES:
- Negative values: Primas_devengadas and siniestros_devengados can be negative
  (this is valid in insurance accounting, not an error). Ratio calculations
  handle negative values correctly and only protect against zero division.
- Extreme ratios: Combined ratio can exceed 1000% in rare cases. The treemap
  visualization handles these gracefully with proper labeling.
- Market averages: Calculated as mean of individual company ratios (not
  weighted by company size) for fairer peer comparison.

TREEMAP VISUALIZATION:
- Text wrapping algorithm ensures long ramo names display properly
- Minimum box size (5% of max) ensures small ramos remain visible
- Dynamic font sizing provides visual hierarchy while maintaining readability
- Distinctive color palette (forest green/crimson red) different from other UI
